# Tab5Symbian
Projeto independente para M5Stack Tab5, com interface inspirada no Symbian.
Trabalhar nesta pasta. Escrever implementação original; não copiar código de aplicações vizinhas.
O documento normativo é plano_sistema_s60_tab5.md. Implementar suas fases incrementalmente; README.md e ROADMAP.md são resumos.
Shell, apps, recursos e persistência ficam exclusivamente no SD em /SymbianOS, quota total de 4.000.000.000 bytes. Teclado oficial I²C obrigatório.
Não executar flash, monitor, erase-flash nem abrir serial sem pedido explícito.
Não publicar no GitHub. Código original MIT; preservar licenças de dependências.
Não usar marcas, ícones, sons ou código proprietário do Symbian/Nokia.
Distinguir testes de host, build ESP32-P4 e medições físicas. Não declarar validação física sem executá-la.
