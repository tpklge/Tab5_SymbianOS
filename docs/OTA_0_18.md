# OTA — 0.18.0 / API 14

A revisão usa agora o mesmo validador no host e no ESP32-P4. O teste de host lê o BIN real compilado, não uma imagem simulada: verifica SHA-256, cabeçalho, projeto e limite do slot. Exercita corrupção, truncamento, outro chip/projeto, ZIP no lugar de BIN, arquivo ausente, SHA malformado, cancelamento e capacidade insuficiente. Não grava flash.

O validador lê blocos de 4 KiB (antes 16 KiB), aceita hexadecimal maiúsculo/minúsculo, CRLF, espaço final e BOM UTF-8, mantendo obrigatórios exatamente 64 dígitos do hash esperado. Não cria um hash esperado a partir do próprio arquivo recebido. Há cessão periódica de CPU durante a revisão. O erro genérico foi substituído por motivo específico e relatório em /SymbianOS/logs/update.txt: etapa, slot real, capacidade, bytes, versão da imagem e hashes esperado/calculado. A revisão bem-sucedida continua sendo necessária antes da instalação; o hash é novamente verificado ao gravar o slot inativo.

Uma revisão cancelada antes voltava como imagem inválida. Além disso, o hook Lua podia transformar o cancelamento de uma chamada nativa demorada em falha do aplicativo. Cancelamento agora preserva a última tela válida, não marca o aplicativo como quebrado e não sobrescreve lua-fault com uma falha fictícia. A regressão provoca um cancelamento real pelo hook Lua depois de voltar da chamada nativa.

O aplicativo Atualizações inclui Diagnóstico OTA. No app Testes e medições, o ícone de informação leva a Atualizações. Uma falha de revisão nunca é anunciada como corrigida por ignorar o hash ou a capacidade. Se o dispositivo usa outra tabela de partições, o relatório mostra a capacidade efetiva; nenhuma tabela é alterada automaticamente.

Os pares runtime.bin/runtime.sha256 do ZIP incremental, SD completo e kit runtime-OTA são gerados a partir do mesmo BIN e conferidos na distribuição. Instalação pelo launcher e validação OTA física são fluxos distintos. Nenhum flash, monitor ou serial foi executado. O usuário confirmou que os flashes azuis de e-mail cessaram na 0.17.1; isso não valida fisicamente a revisão OTA da 0.18.0.
