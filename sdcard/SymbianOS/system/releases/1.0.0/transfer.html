Enviar arquivos

Selecione um ou vários arquivos. Máximo de 64 MiB por arquivo; nomes de até 100 caracteres, sem espaços. Arquivos existentes são preservados.

O progresso mostra os bytes confirmados pelo Tab5. Resultados e erros permanecem abaixo enquanto esta página estiver aberta. Se houver falha, corrija a causa e selecione novamente o arquivo.
Use o serviço na mesma rede Wi-Fi. Encerre “Enviar arquivos” no Tab5 para invalidar o token. Atualizações do sistema são feitas pelo launcher.
